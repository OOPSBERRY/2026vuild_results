# 고요한 나의 책상 — 구현 핸드오프

## 실행

- 정적 프리뷰: `http://127.0.0.1:4173/` (검토 중인 로컬 프로세스)
- 소스: 이 폴더의 정적 HTML/CSS/JavaScript/Three.js r128 구성. 배포·커밋·푸시는 수행하지 않았다.

## 구현 범위

- 입장하기 → 양쪽 월넛 문 3D 힌지 전환 → 기존 `의자에 앉기` 흐름.
- 문 전환 중에는 배경과 닫힌 도구 패널을 `inert` 처리하며, Tab은 입장 제어 안에서 순환한다. 중복 클릭은 무시한다.
- 기존 3D 물건 선택과 `links.js` 데이터·빈 URL의 `곧 열려요` 동작은 유지했다.
- 각 물건은 DOM 상세 패널을 연다: 고전 읽기/어린 왕자 세부 화면, 마음 선택, 1분 타이머, 한 줄 기록(localStorage).
- 씬은 실제 Three.js의 월넛 알베도, 책장 스파인 아틀라스, 황동/검은 가죽/아이보리/버건디 재질을 사용한다.

## 시각적 범위의 정확한 설명

제공된 아트는 재질·색·분위기 참고다. 결과물은 그 이미지를 장면 배경으로 붙인 결과가 아니라, 해당 팔레트와 재질을 적용한 **스타일라이즈드 Three.js 서재**다. 따라서 포토리얼 복제나 참조 이미지와의 픽셀 일치는 주장하지 않는다.
